# Security Policy

## Supported versions

Security fixes are provided for the latest `1.x` release of Noreviq Filament
Theme. Users should update to the newest available patch release before
reporting an issue.

| Version | Supported |
| --- | --- |
| Latest `1.x` release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/Y-Jallad/noreviq-filament-theme/security/advisories/new)
to share the report privately. If private reporting is unavailable, email
`eng.yousef.aljallad@gmail.com` with `[SECURITY]` in the subject line.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. Reports will be reviewed privately, and a fix and disclosure will
be coordinated when the issue is confirmed.
